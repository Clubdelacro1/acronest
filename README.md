# Acronest 2027

Web del evento Acronest · 4ª edición · 7–11 de julio de 2027 · Cortijo Casería del Mercado, Las Alpujarras (Granada).

- `index.html`: la web (inglés y español).
- `inscripcion.html`: formulario de inscripción. Guarda cada inscripción en la planilla "Acronest 2027 · Inscripciones" (cuenta acronest.fest@gmail.com) a través de Google Apps Script.
- `backend/inscripciones.gs`: copia del código de Apps Script que recibe las inscripciones.
- `img/`: fotos, logo e ilustración.
